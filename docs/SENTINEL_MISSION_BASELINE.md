## Preservation and integration gates

| Invariant | Integration check |
|---|---|
| P1, original decoder compatibility | Original package/decoder pairs and negative controls, with original identities |
| P2, recovery and bounds | Unchanged legacy source/runtime pins, capacities, API regressions |
| P3, frozen evidence | No changes to historical proof, receipt or artifact bytes |
| P4, accepted tests | Every applicable admitted regression in its declared environment |
| P5, retained failures | Original failed inputs/results and additive repair records |
| P6, capabilities | Full diff against the pinned baseline; no deleted or weakened controls |
| P7, absent authority | Source instructions and historical approvals remain data |
| P8, proof scope | Component contracts, source and tool identities named separately |
| P9, original evidence | Exact byte recovery and source/derived coordinate separation |
| P10, epistemic distinctions | Proposed reading, structure, model result and world truth remain distinct |

These are mandatory gates, not a completed full-integration report. The existing
conditional reference-fidelity checker remains conditional exact-text comparison.
It does not establish OCR accuracy or semantic completeness. The original
`transport/meaning/1`, `/2` and `/3` meanings and old decoder bundles are unchanged.

The reported full-share concern was inspected by two reviewers. The legacy
meaning package checks its complete canonical share. The document profile has
an explicitly different inert-suffix contract. No operative canonical mismatch
was independently established. A proposed new check that would validate the
display ornament conflicted with the user's earlier constraint and was rejected.
No ornament-aware decoder or manifest check is introduced.

complete this mission. The existing owner-hour, calendar, benefit, external human
validation and pilot requirements remain in force; no budget or acceptance gate
is reset by the new branch. No superiority, universal understanding, final release
approval or legal authority is asserted.
