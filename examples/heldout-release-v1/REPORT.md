The museum fixture now completes the full path: frozen source, matched share
text and meaning ZIP, a fresh receiving agent, an unedited proposed patch, and
separate source and behavior checks. Both transport and the original-document
baseline succeeded on the retest. Transport used more calls and more time in

## What was built

The original renderer repeated complete dictionaries for each meaning unit.
This fixture exceeded the readable-lexicon limit, then an intermediate rendering
exceeded the archive limit. Both refusals are retained. The renderer now shares
exact dictionary content in a reversible readable registry. Symbol meanings,
operator definitions, unit trees, context links and source frames remain intact.
Tests reconstruct every canonical unit from its references and the registry.
The original limits remain unchanged.

A separate qualified native-reuse command checks the held donor installation,
source and build records, unchanged native inputs, bootstrap and native bytes.
It derives new runtime and installation identities for the renderer change.
This operation did not compile native code or run a new proof campaign. It does
not alter the original build gate or make independent builds interchangeable.

The first transport recipient then encountered a complete focus response that
the surrounding tool truncated. It stopped without submitting. The reader now
offers `focus_page`: bounded chunks, complete-result and per-page digests,
contiguous offsets and explicit end markers. Every call still checks the full
package. The fresh retest used exactly the same package bytes, new helper
bindings and fresh recipients; no failed answer was edited into a success.

## Remaining boundary

Complete source text and opaque propositions still carry details that the typed
reading does not express. They are visible as incomplete readings, residuals
and uncertainty, not silently promoted to semantic completeness. Correct parsing,
a finite table and a source review do not prove general English entailment.
The finite checker interprets a restricted expression as data; it never runs
candidate Python. No historical approval or decoded obligation grants current
execution authority.

Ada/SPARK source and proof obligations are unchanged. This wave tests Python
rendering, runtime derivation and receiving mechanics; it adds no whole-system
proof. Existing proof scopes remain limited to their named structural contracts.
External-user validation, desktop-client acceptance, marketplace publication,
native-compaction comparison and cross-model acceptance remain unperformed here.
The next comparative gate is a frozen continuation campaign across repeated
handoffs and constrained context, retaining the plain-source baseline and all
errors and costs.
