# Frozen repeated-transfer obligations

This is a source-only predeclared synthetic comparison. No model outputs were read or used to select criteria. Existing five public handoff-v1 source files are byte-identical; METRICS is a new explicit synthetic record. Its entire correction, historical/current reports and scope conditions remain in one opaque anchored unit. Integrity/opaque transport does not prove semantic completeness or source authority.

There are exactly two arms, indexed-original and transport, and three fresh receiving hops per arm. Every hop gets the identical task/output shape/source index, same model and reasoning effort selected by the dispatcher, and fresh access to the same arm's complete identity-checked sources. Hop 1 has no predecessor. Hops 2 and 3 additionally receive the previous same-arm exact first observed final plaintext JSON as untrusted data. No other chat history, evaluator files, expected answer, scoring, improvement feedback or alternate candidate is delivered. Fixed dispatch order is original1, transport1, transport2, original2, original3, transport3. No retries or prompt optimization after any outcome.

The strong original baseline gets exact original bytes and a literal heading/byte-offset index of all six files, identical in both arms. The index contains no answer, semantic interpretation or correction conclusion. Five relevant source files each fit one 4096-byte page. Source IDs, metadata, order, source-page bounds, candidate/output cap, session calls and outer task are matched. Transport additionally offers declared graph focus; original gets no decoder, graph or expected answer. A full-source third arm is not required for this bounded comparison; original can read every relevant file each hop with the same tools. Account those calls rather than withholding them.

Every obligation is mandatory at every hop; no average, aggregate score, byte saving or later recovery overrides a failure:

The deterministic witness checker compares required structure, values, evidence inclusion, pending uniqueness and raw budget. Independent source/protocol review must also assess actual calls, complete conditions/exceptions, exact predecessor delivery, model identity, final/candidate consistency and no forbidden access/action. A checker result alone is WITNESS_MATCH, not full acceptance.

Retention acceptance requires both arms' all three hops to meet every obligation with complete protocol evidence. A failed candidate fails that arm's retention even if a later hop recovers from fresh sources; report recovery separately. Any protocol/refusal/integrity or missing/ambiguous-final failure is retained and the affected arm stops. A witness or codepoint-budget failure may continue using the exact unchanged first final if the existing byte cap permits; no corrected/substitute predecessor is allowed and the failed retention remains failed. If only one arm passes, that is a bounded observed difference in this fixture. If both pass, report bounded fidelity parity. Neither outcome establishes a population rate, causal superiority or native compaction.

Record separately for each hop: exact incoming/outgoing bytes/codepoints/digests; task/index/interface/binding/manifest and predecessor pins; helper/decoder/payload delivery bytes; all reader calls and returned bytes including refusals; source/page/focus reads; fresh source accesses; saved candidate/final and any differences; wall-time observations; unaggregated usage records and their peak observed input sample. Cumulative usage snapshots are never summed; per-request context peak, monetary cost, energy, hidden access and OS isolation stay UNKNOWN unless independently established. Report setup/copy/encode costs separately from receiving costs; no amortization assumption is an observed reuse result.

This campaign tests repeated continuation WITH source refresh. It does not isolate source-free retention or native context compaction. Earlier trials remain separate evidence and are not relabeled. Model runs, dispatch equality, source-grounded outcomes, full trace completeness and comparative benefits are UNRUN/UNPROVEN until their actual evidence exists.
