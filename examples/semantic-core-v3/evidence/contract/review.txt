Closed grammar and typing
AST operations are exactly pred, not, and, if, all, some, must. No var node, generic quantifier body, equality, arithmetic, quantity, clock, substitution or term construction. Ground predicate arity is zero, one or two; predicate declarations give that exact arity. all(P,D) and some(P,D) require a declared unary predicate P and explicitly listed domain D. This is a deliberately narrow finite monadic aggregation fragment, not first-order logic. Terms, predicate symbols and domain symbols share one globally unique namespace with aggregate cardinality at most 64. Model tuple records at most 256; AST nodes at most 256. Every reference is an exact identifier with role checked; no case folding, Unicode normalization, same-spelling alias, implicit domain closure or inferred tuple.

pred/not/and/if/all/some return Fact. not takes one Fact; and and if take two Facts. must takes one Fact and returns Norm. No Norm may be an operand of any grammar3 operator, including must and and. Preserve the old evaluator's separate Norm_And capability in its old profile, but do not accidentally import it into this closed grammar. A Fact result carries Outcome Unknown; every Norm result carries Truth Unresolved, including satisfied and violated norms. There is no authorization/permission field that can become true; report execution_authority NONE unconditionally.

Truth and model rules
Use the explicit strong Kleene truth tables in oracle.json, not host-language Boolean coercion. Implication is negation of antecedent disjoined with consequent: only known true antecedent with known false consequent is known false; unresolved antecedent and known false consequent stays unresolved. Native SPARK, not Python, resolves tuples and performs every consequential semantic fold. Missing tuple is Unresolved. Conflicting known-true/known-false rows for one exact ordered tuple are Unresolved, independent of row order. Preserve explicit unresolved evidence when mixed with a known row as Unresolved, consistent with existing Resolve_Mask (transport_bound_eval.ads:7-14); do not silently upgrade it to known. Reject malformed rows, unknown truth labels, unknown identifiers, wrong arity, wrong symbol role, and over-budget input rather than treating them as missing facts.

Domain members are unique declared term IDs; no duplicate-member deduplication. Domain lists are finite and explicit; empty domain all=True and some=False. all is False if any instance is False, True if every instance is True, otherwise Unresolved. some is True if any instance is True, False if every instance is False, otherwise Unresolved. Evaluate each member with the same exact unary tuple lookup used by pred. No floating-point JSON values, nonfinite constants, booleans as integers, duplicate object keys, unknown fields, trailing data or coercion. Validate bounded complete inputs before semantic short-circuiting so malformed or over-budget rows cannot hide behind a decisive first value. With unary aggregation only, the AST/domain/tuple bounds suffice for a finite nested-loop implementation; preserve fixed storage, bounded loops and explicit failure reset.

Source-language conformance and conditional scope
Use a NEW surface profile with exact complete shape: ID: When EVENT, ACTOR shall ACTION[ , unless CONDITION]. (The actual optional delimiter is comma-space followed by unless-space, with no preceding extra space.) Retain the old technical-requirements/1 parser unchanged. Require When, shall and final period exactly; do not inherit shall not, should, may, optional When or within handling. Require all role slices nonempty and precisely source-anchored; reject ambiguous delimiter repetition, extra sentences, unsupported punctuation and noncanonical padding. Parse the complete intended source unit; no first-sentence or recognized-prefix success.

Canonical evaluation scope is must(if(EVENT, ACTION(ACTOR))) or, with exception, must(if(and(EVENT, not(CONDITION)), ACTION(ACTOR))). EVENT and CONDITION are explicitly bound nullary predicates; ACTION is a unary predicate applied to the actor term. Source ID is metadata, never an extra fact. Mandatory authored-tree equality includes operator, operand order, predicate identity, actor ID and exact role source anchors, modulo only a documented canonical node numbering. if(EVENT,must(ACTION)) and and(must(EVENT),must(ACTION)) are type errors, never alternative readings. With known-false EVENT or known-true exception the material conditional is satisfied even if ACTION is false; explicitly label satisfaction conditional/vacuous, not permission or evidence the action occurred. Unknown guard plus false action yields Unknown; unknown guard plus true action yields Satisfied under the selected truth table.

There is a boundary requiring an explicit implementation decision: arbitrary free-text EVENT/ACTION strings can conceal causal, attribution or belief language. Existing atom() only rejects punctuation and a short reserved-word list, so it accepts e.g. because and believes as ordinary role text (transport_requirement_language.py:21-24,44-46,81-104). If such language must always stay documentary, define a finite role-token vocabulary/whitelist or a precise rejected-token grammar, or require role values to be opaque named labels whose meanings are explicitly outside the semantics. A claim that arbitrary English has been classified or understood would be unsupported. All surfaces outside the admitted exact shape remain documentary with NOT_IN_FRAGMENT; if an input explicitly requests evaluated-fragment conformance and its authored tree differs, REFUSED. No operator stripping or automatic reinterpretation.

Source/model identity recommendations
Model symbol identity is its declared ID, not source spelling or leaf-node index. For each declared term/predicate/domain, retain an explicit source binding when claiming source alignment: source ID, source digest, half-open byte span and exact quote. Require the selected actor, event, action and condition bindings to match the parser's role slices. Bind every domain member term to an explicit declaration; extra model vocabulary may be anchored to a separate retained model declaration source, not invented as a quote from the requirement. Predicate tuples must use declared IDs, preserve order and exact arity. An extra anchor is only custody evidence, never proof that a report is true. If the design admits unanchored finite model constants, label them model declarations and do not claim all model terms came from the natural-language source.
