# Frozen independent standard export reader contract

Implement only this bounded informational reader using Python standard library. No producer/codec modules, native executables, subprocess, network, source execution or directory creation. Target install/read_transport_export.py. API read_export(directory, expected_export_sha256) returns validated object with manifest, ordered source byte records, exact explanation bytes and exact metadata bytes plus parsed unverified metadata. Define ExportReadError with stable error code; fail explicitly, never truncate, guess or fall back. API results are data only and carry authority NONE.

CLI: inspect EXPORT --expect-export-sha256 PIN; recover EXPORT OUTPUT --source ID --expect-export-sha256 PIN; explanation EXPORT OUTPUT --expect-export-sha256 PIN; metadata EXPORT OUTPUT --expect-export-sha256 PIN. All commands completely validate export first. Only recover/explanation/metadata write, exactly one explicitly requested new regular file, create-only, no overwrite or follow links, no extra newline. On refusal no accepted output remains. Bound stdout JSON including final newline to 131072 bytes; errors bounded and nonzero, no partial successful stdout. inspect excludes raw source/explanation and full nested metadata; return ordered source checklist plus lengths/digests, package identity and declared schema versions. No all-context expansion by default.

## Pin and byte bounds

PIN mandatory lowercase SHA256 hex of exact export.json bytes, independently held outside export. Hash before parsing; refuse mismatch. Do not compute a new expected pin from received input. All member bytes including export.json aggregate <=131072; each <=131072; 4..19 files inclusive. Source count 1..16; source bytes aggregate <=65536 and each <=65536; text bytes <=65536. Empty sources and empty explanation allowed. Finite reads cap+1; enforce aggregate budget before retaining additional bytes. No truncation. No extra files or directories. Input manifest and metadata nonempty. read_export uses bounded work/memory and no user-controlled recursion. CLI process limits explicit (address-space 268435456, CPU 60, file size 131072 or stricter documented bounds); no per-source implicit unlimited retries.

## Exact layout

Root exactly export.json, metadata.json, UNVERIFIED_AI_EXPLANATION.txt, sources directory. sources exactly declared ID.bin files. ID regex [A-Z][A-Z0-9_]{0,31}, path exactly sources/ID.bin. Reject symlink in any input/output ancestor or leaf (including root and sources), special entries, nonregular files, hardlinks st_nlink !=1, repeated dev/inode aliases, nested folders, extras/missing files, path traversal, backslashes, absolute/member aliases and duplicate paths. Directory-relative opened descriptors with O_NOFOLLOW/O_NONBLOCK and fstat regular-file checks; bound all enumerations. Hold file bytes after reading and validate those same bytes; do not reread selected output from an unchecked path. State hostile concurrent same-user mutation is not fully isolated by hash checks.

## JSON

Strict UTF-8 with no BOM and no unpaired surrogate values. Reject duplicate keys including escape-equivalent names. Reject floats/exponents/NaN/Infinity; numbers exact integers only, booleans never accepted as integers. Integer token <=20 decimal digits excluding sign. Structural nesting <=12; object fields <=256. Bound iterative parsed traversal to 131072 value/key nodes and total decoded string UTF8 bytes <=131072 per document. Every node/key/string consumes budget. These parser limits apply to both manifest and metadata and documentary runtime subtrees. JSON literal strings preserve exact characters; recovered source/text/metadata bytes never normalize. Unknown fields rejected only where exact sets below specified; opaque nested metadata explicitly remains unverified data.

## Metadata

Exact top-level v1 keys schema,identity,sources,interpretations,uncertainties,relations,coverage,assurance; v2 same plus meaning_units. identity matches manifest. sources list same ordered source IDs/bytes/digests; source record exact keys id,label,media_type,provenance,bytes,sha256; label/media_type/provenance strict strings, media_type nonempty. Interpretations, uncertainties, relations and v2 meaning_units must be lists; coverage and assurance objects. Their nested values remain bounded unverified JSON with no semantic/schema certification. ## Claim ceiling

Successful check status VERIFIED_AGAINST_PINNED_EXPORT. Successful selected output status EXACT_PINNED_EXPORT_BYTES_RECOVERED. Declare metadata UNVERIFIED, authentication NOT_PROVIDED, authority NONE, original_comparison NOT_PERFORMED, producer_runtime NOT_EXECUTED, raw_envelope NOT_RECONSTRUCTED, semantic_completeness NOT_CLAIMED, explanation_entailment UNPROVEN. The pin binds manifest and its hash-checked members, not original source identity independent of export, native decode validity, source truth, authorship, runtime execution or currency. Freeze independent oracle before implementation.
